# Orchestrator-Gedaechtnis (Export, Stand 13.09.2026)

Kopien der Claude-Code-Gedaechtnisdateien des Orchestrators (Fable) zu Grimlight.
Zweck: auf einem neuen Rechner startet Claude Code ohne dieses Gedaechtnis; eine
neue Sitzung liest ZUERST design/BETRIEB_NEUER_RECHNER.md, dann diese Dateien
(project_grimlight.md enthaelt den Block "WIEDEREINSTIEG NACH COMPACT" mit dem
aktuellen Stand, den offenen Michael-Punkten und den Lehren), dann die letzte
Uebergabe in uebergaben/. Die Direktiven-Dateien (feedback_*) sind Michaels
Arbeitsregeln. Agent-IDs darin gelten nur fuer die Ursprungsmaschine.
Aktualisierung: bei jeder Uebergabe neu exportieren (cp aus
~/.claude/projects/-home-coder/memory/).
